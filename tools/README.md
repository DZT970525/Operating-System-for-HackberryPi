# HackberryPi image build sources

This directory holds the reviewed source bundle for the HackberryPi PINN multiboot refresh. It contains partition adapters, image checks, source manifests and disposable tests for the eight converted systems.

The manually dispatched build verifies the source bundle before running it, checks the published input images, and prepares new packages in a release draft. The public PINN catalog is updated after the converted packages pass verification.

See the repository homepage for currently published installation methods.
